# smart-tour-platform
this is a web platform that connects local and foreign tourists with verified drivers and professional translators for day tours and custom trips across Sri Lanka



## Project Objectives

- Help tourists discover tour packages in Sri Lanka.
- Allow tourists to find drivers and translators.
- Provide options for ready-made and customized tours.
- Display estimated tour costs.
- Support online tour booking.

## Planned Features

- User registration and login
- Tour package browsing
- Driver and translator listings
- Custom tour planning
- Estimated tour cost calculation
- Tour booking management
- Online payment integration

## Technologies

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** Microsoft SQL Server
- **Database Management Tool:** SQL Server Management Studio (SSMS)
- **Version Control:** Git and GitHub

## Project Status

Currently under development. The features listed above are planned and may not yet be implemented.
